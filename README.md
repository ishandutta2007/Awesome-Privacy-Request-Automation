# Awesome-Privacy-Request-Automation

## Top Privacy Request Automation (DSAR) Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Data Subject Access Requests, Erasure, Privacy Rights Fulfillment, Discovery & Compliance Workflows*

**Last updated: September 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Privacy Request Automation (DSAR)**. These systems help organizations receive, verify, orchestrate, and fulfill data subject requests (access, deletion, correction, etc.) under GDPR, CCPA/CPRA, and similar privacy laws.



**Examples** include OneTrust, Securiti, DataGrail, Transcend, BigID, TrustArc, WireWheel, Osano, Didomi, Privado, and DataGuard (the category leaders).



**Open-source emphasis**: Full enterprise DSAR platforms are largely commercial. The strongest open option is the **Fides** ecosystem (including fidesops) for privacy-as-code and DSAR orchestration. Additional experimental standards and tools exist. This section highlights practical open alternatives and is realistic about the gap.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[OneTrust](https://www.onetrust.com/)**  

  Comprehensive privacy platform with strong DSAR automation, consent, assessments, and broader privacy program management.



- **[Securiti](https://www.securiti.ai/)**  

  Data command center platform offering privacy, data security, and DSAR automation with discovery and AI-assisted workflows.



- **[DataGrail](https://www.datagrail.com/)**  

  Privacy platform focused on DSAR automation, data mapping, and cross-functional request coordination.



- **[Transcend](https://transcend.io/)**  

  Developer-oriented privacy infrastructure for data rights, consent, and automated fulfillment of access and deletion requests.



- **[BigID](https://www.bigid.com/)**  

  Data intelligence platform strong in discovery and classification, supporting privacy request fulfillment across complex data estates.



- **[TrustArc](https://trustarc.com/)**  

  Privacy and compliance platform providing DSAR workflows within broader privacy program management.



- **[WireWheel](https://wirewheel.io/)**  

  Privacy operations platform supporting data subject requests, data mapping, and compliance workflows.



- **[Osano](https://www.osano.com/)**  

  Consent and privacy platform that includes DSAR intake and operational request handling.



- **[Didomi](https://www.didomi.io/)**  

  Consent and preference platform with capabilities that support privacy request and rights management.



- **[Privado](https://www.privado.ai/)**  

  Privacy platform focused on code-level data flow discovery and related privacy engineering capabilities.



- **[DataGuard](https://www.dataguard.com/)**  

  Privacy and compliance solutions that include support for data subject request processes.



## Open-Source GitHub Projects

- **[Fides / fidesops (Ethyca)](https://github.com/ethyca/fides)**  

  Open-source privacy-as-code platform. Fidesops provides DSAR orchestration by connecting to databases and systems to fulfill access and erasure requests programmatically.



- **[DSAR open standards and engines](https://github.com/inthhq/dsar)**  

  Open-source efforts to define programmatic standards and runtimes for handling data subject access requests.



- **[DARPAL and process automation language projects](https://github.com/DaSKITA/darpal)**  

  Experimental schemas and tools aimed at automating data subject access request processes.



- **[Privacy request workflow open prototypes](https://github.com/)**  

  Community projects for intake forms, ticketing, and basic orchestration of access and deletion requests.



- **[Data discovery and catalog open tools](https://github.com/)**  

  Open data catalog and discovery components that can support locating personal data for DSAR fulfillment.



- **[Consent and preference open backends](https://github.com/)**  

  Open systems for recording consent that can integrate with DSAR workflows.



- **[Identity verification open helpers](https://github.com/)**  

  Components for verifying the identity of requestors before fulfilling privacy requests.



- **[Audit logging and evidence open frameworks](https://github.com/)**  

  Tools for maintaining records of DSAR handling for compliance evidence.



- **[Connector and integration open libraries](https://github.com/)**  

  Open connectors for common SaaS and database systems used in privacy request automation.



- **[Privacy policy and notice open generators](https://github.com/)**  

  Supporting open tools for privacy notices that accompany DSAR processes.



### Additional Strong Open-Source Options

- Starting with the **Fides** ecosystem for privacy-as-code and automated DSAR fulfillment against connected systems.

- Using open intake and workflow tools for smaller organizations with limited data systems.

- Combining open discovery tools with commercial DSAR platforms for hybrid approaches.

- Accepting that deep data discovery across complex environments, enterprise-scale orchestration, legal workflow management, and continuous regulatory updates still favor commercial platforms (OneTrust, Securiti, DataGrail, Transcend, BigID, etc.).

- Focusing open-source efforts on controllable, auditable fulfillment pipelines where data sovereignty is critical.



**Frameworks for building custom systems**: Deploy Fides/fidesops → connect to data stores and SaaS via connectors → define privacy request policies → receive and verify requests → execute access/erasure workflows → maintain audit logs. Suitable for technically capable teams. Most organizations with complex data landscapes continue to rely on commercial DSAR platforms for operational reliability and compliance support.
